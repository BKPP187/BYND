# 描写检查与完成后朗读

“照着写”以当前示范字形作本机位置和完整度检查，适用已有字表；不检查笔顺，不把结果当作自由手写 OCR 或书法评分。

- 灰色示范和检查蒙版由同一字体、同一画布模板生成，避免 DOM 文本与 Canvas 基线错位。固定 560px 逻辑坐标保留原笔迹，检查时缩至 140px。
- 比较笔迹是否接近示范，以及示范是否被充分覆盖；额外检查独立点、元音标记等连通部分，避免只描主体就通过。明显偏离或漏写时整段用户笔迹标红，保留原笔迹供撤销、补写或重写。
- 抬笔后立即检查并给出颜色和文字反馈；停笔约 1 秒自动朗读当前原文字形，沿用对应语言及现有语音绑定/系统语音通道。通过与未通过都可听正确目标读音；空白和取消的输入不触发完成。下一笔会取消上一轮等待并保留笔迹。
- 自动反馈不增加完成次数、不清空笔迹；点击“完成描写”后，只有检查通过才计入完成次数。自动读过同一轮笔迹时，手动完成不重复朗读。保留可见笔迹，“再练一次”清空进入下一次。保存失败仍保留笔迹，显示重试保存，不增加次数或报告成功；损坏的记录不会被覆盖。
- 多指输入不合并成一笔；撤销、清空、切换语言/字表/字形会重置检查结果。语音缺失或播放失败使用既有明确提示，重绘后仍保留检查结果及笔迹。

实现：apps/study/study-trace.js；UI 与完成流程：apps/study/study-app.js。测试：tests/study-trace.test.cjs、tests/study-app.test.cjs；浏览器：scripts/check-study-trace-browser.cjs。

验证包括：真实鼠标指针画出的三笔 H 通过，单笔 H 漏写不通过，泰语格内乱画标红，泰语示范中心线作为正样本通过；后者验证描写对齐，不等同于真实用户手写识别准确率。测试还检查实际红色画布像素、保存次数、语音缺失、320/375px 窄屏及 47/59px 两种安全区。
