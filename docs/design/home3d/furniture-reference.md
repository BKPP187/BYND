# 小屋家具 · 参考图实现

奶油童话采用奶油白、浅木和薄荷绿；欧式复古采用深胡桃木、象牙白织物与克制的黄铜细节。两套共用交互尺寸，分别制作木框、曲线轮廓与软装细节。用户上传的六张等距室内图用于配色、家具比例与造型参考。

家具为原创建模的实时 3D 几何，支持已有装修流程的拖动、旋转、拾取与保存。没有把参考图作为房间背景，也没有将低分辨率画布通过 CSS 放大。

- 床与沙发：分块靠背、独立坐垫、枕头、床沿、毯子垂边和流苏；保留角色坐卧支撑高度。
- 柜子与书架：实木顶板、框线柜门、抽屉和黄铜把手，书架有真实层板及书本。
- 欧式系列：曲腿、拱形木框、卷纹扶手、金属冠饰与灯罩骨架。
- 厨房：薄荷绿烤箱、水槽、双门冰箱；水槽有实际凹下的盆底及弯曲水龙头。
- 新增十二款：两套风格各有水槽、冰箱、餐桌、抽屉边柜、壁炉和衣柜；可从装修家具目录中选择。

几何在每件家具内按材质合并，单件最多 10 个绘制批次、少于 10,000 个三角形。细节仍是几何，可随相机放大；织物的微纹理只表达材质，不承载家具轮廓。房间保留现有 75%～85% 可视区域布局、平滑拖动与缩放，以及独立旋转相机接口。画布分辨率继续跟随实际视口、DPR 和设备质量预算，手机硬件帧率需在真机验证。

## 整间硬装与软装

参考的适用范围已扩展到房间外壳。`interiors.js` 提供七套可保存的整间搭配：奶油花园（鼠尾草碎花、浅橡木拼花）、法式晨光（象牙卷纹、大理石）、森系书房（亚麻条纹、胡桃拼花、百叶窗和藤蔓）、玫瑰阁楼（玫瑰砖墙、棋盘砖、双拱窗）、自然公寓（暖灰石灰墙、橡木人字拼、细框直窗）、粉白花园（粉绿花条纹、玫瑰方砖、白框粉色软包）、黑白星落（白砖黑框、黑白棋盘、细脚家具与圆茶几）。每套同步当前家具的外观，以及护墙线、窗帘、挂画和地毯；不改变家具占地或人物支撑点。

从「装修 → 墙地套装」进入，可整套切换，也可单独选择八种墙面和八种地板。风格按房间、同住角色独立保存。已有单独布置的家具保留自己的外观，直到用户主动套用完整风格；后续添加的单品继续使用其选定风格。昼夜光照仍单独选择。

墙面、地面和地毯图案均为代码绘制的原创 1024px 材质纹理，不是将参考图贴到房间上。地板按板材实际尺度重复，并使用真实场景透视、光照、阴影及纹理预算。换房间时清理旧表面材质和 GPU 纹理，避免多套高分辨率硬装积存在显存。

`node scripts/check-home3d-interiors-browser.cjs` 生成七套真实 WebGL 截图，检查单独硬装选择、重载、保存失败、320px 选择器和资源释放，结果位于 `artifacts/home3d-interiors`。

家具选择界面按用户图二改成底部分类栏与横向卡片，卡片为真实模型的等距预览，不再使用二维示意图；数量表示当前房间已经摆放的同款家具，不虚构库存或评分。电视为独立的正向模型，局部 +Z 是黑色屏幕的观看面，默认朝向沙发。
