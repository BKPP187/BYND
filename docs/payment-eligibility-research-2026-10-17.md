# BYND 支付接入与境外托管核查

核查日期：2026-10-17。范围：内地个人开发者、没有营业执照、境外托管且无 ICP，销售一次性 ¥13.88 的 Android 软件授权，要求服务端可信核款后自动发码。只研究公开规则，没有申请、签约、付款、迁站或修改销售开关。

## 结论与证据边界

本次未找到支付宝官方明确允许上述条件同时成立、长期用于纯线上软件销售的网站直连接入豁免。这是公开资料核查的结果，不是断言官方绝无个案或新产品；最终需商家平台针对真实业务审核确认。

### 新版规则优先于旧帮助中心

- [支付产品额度规则介绍](https://opendocs.alipay.com/b/039qjw)是用户截图对应的新版文档。搜索索引确认“网站/APP 已上线 + 营业执照未提供或不完整”列为单笔 ≤50 元、单日 ≤1000 元、长期有效。用户截图同时明确：已上线网站链接需完成 ICP；未上线可提交首页、商品/服务页、支付页 demo，审核通过后的使用期为 30 天。不能把“营业执照可缺省”误解为“网站 ICP 也可缺省”。
- [电脑网站支付申请条件](https://opendocs.alipay.com/b/03ah5w?pathHash=4542d144)的官方搜索索引仍列有网站 ICP 要求。
- 这些新版文档为动态页面，普通网页抓取返回空正文；上述新版表格细节分别由用户提供的真实官方截图及官方域名搜索索引交叉核对。未取得登录后的审核结果。
- [旧帮助中心同名规则](https://help.alipay.com/enterprise/knowledgeDetail.htm?knowledgeId=201602191944)仍可被检索，但显示的资质/限额与用户当前后台有差异。不得用旧页一概断言所有个人都必须有营业执照，或承诺无 ICP 可长期使用。

### 境外托管不等于境外商户

- [阿里云备案场景说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/product-overview/faq-about-icp-filing-applications-in-different-scenarios)区分中国内地与境外服务器。网站托管的备案要求与支付宝产品材料要求分开判断，不能用托管地替代支付宝的准入审核。
- [支付宝国际网站收单产品](https://global.alipay.com/product-detail.htm?bizCode=OPEN_ONLINE_PAYMENT-Website)的 Application Conditions 明确列有有效营业执照、公司资料及法人/股东身份证明。因此不能仅因域名或服务器在国外，就把当前无执照个人账号视为已满足国际收单条件。

### 当面付和 APP 支付并非网站支付的无条件替代

- [支付宝官方产品区别](https://opendocs.alipay.com/support/01rfnp)说明：当面付扫码主要适用于线下实体、面对面场景；APP 支付是商家自有客户端通过 SDK 发起支付，需要相应产品协议。
- 新版规则的 APP 材料栏列有 APP 名称、应用市场下载链接及必要的授权函。它和网站材料不同，但不能据此保证尚未上架的 BYND 可直接获准长期收款。APP 所需上架、备案及商户资质需单独确认，不因为改用客户端支付自动消失。
- 本次未改造 App 支付 SDK，也未把线下收款权限当作获准纯线上销售。

### 第三方备选的已知与未知

- [面包多 Pay 官网](https://p.mbd.pub/)称支持个人，提供微信/支付宝 API；[正式开通文档](https://doc.mbd.pub/fu-wu-kai-tong)要求较严格审核、闪电认证及渠道开通，不能采信首页“10 分钟开通”作为保证。
- [费用文档](https://doc.mbd.pub/untitled)标示每笔 2% + ¥0.10。对 ¥13.88 的算术估算为 ¥0.3776，通常约 ¥0.38；最终以实际账单计费精度为准。
- 公开资料未足以确认“当前无 ICP 的 BYND 一定获批”。因此仍只是候选，未选择、注册或接入。用户已表示不接受高费用，不替用户决定。
- 未核实具体服务商资格、收单合同与线上业务准入的“个人免备案接口”广告，不作为可靠接入结论。

## 补充候选：爱发电 Webhook + API（用户提供线索后核查）

这条路径此前未列入候选，需补充。它是爱发电平台收款后交付权益，与 BYND 网站直接签约支付宝的路径不同；不能从平台收款推断 BYND 所有备案或经营要求均自动免除，也尚未取得 BYND 的平台准入确认。

- [平台介绍](https://guide.afdian.com/)明确包含软件开发者；[开发文档](https://guide.afdian.com/creator/developer)公开订单 Webhook 和凭创作者 user_id/API Token 主动查询订单的接口，技术上可以对接现有 Cloudflare Worker 与 D1 账号授权系统。
- 官方订单字段包含 out_trade_no、买家 user_id、plan_id、total_amount（真实付款）、show_amount（展示金额）、status、redeem_id、product_type、sku_detail。文档规定 status=2 为交易成功，兑换码订单 total_amount 可能为 0；必须按实际付款核对 1388 分及准确方案/SKU，不能只看 show_amount 或“成功”字样。
- 官方公开 Webhook 示例没有可直接验证的通知签名。API 请求签名与 Webhook 身份认证不是同一件事。接入时把回调当作查单信号，凭服务器保管的 Token 请求固定 HTTPS 官方查单接口，确认创作者范围下的真实订单后才履约。文档建议 API 补偿并提示重复回调，应通过唯一订单号、原子写入和补偿查询保证一次发码。
- 账号归属不可只凭用户输入邮箱、昵称或获知订单号。首选[官方 OAuth2 关联授权](https://guide.afdian.com/creator/oauth2)绑定 BYND 登录账号与爱发电买家 ID，核验 state、服务端交换 code、限制可信回调。OAuth2 需向平台申请 clientID/clientSecret，不承诺默认已开放。若未获 OAuth2，需另行验证可信订单关联方案，或采用平台私信交付独立激活码、买家在 BYND 账号兑换的路径，不直接给任意声称该订单的人发码。
- [官方创作者进阶](https://guide.afdian.com/creator/creator-level-up)明确支持自动随机回复逐行发放激活码；该方案是平台内交付后再兑换，和 Webhook 服务端生成并直接归属 BYND 账号的自动流程不同。
- [官方收费 FAQ](https://guide.afdian.com/faq/faq-for-creators)标示赞助金额收取 6%（1% 支付费用 + 5% 平台服务费），创作者得 94%。用户最新已明确确认支付宝和爱发电统一售价 ¥13.88。按爱发电 ¥13.88 算术估算费用 ¥0.8328、净额 ¥13.0472，约 ¥0.83 / ¥13.05，实际按对应售卖方案与平台账单。费用高于现有支付宝直连及面包多 Pay 文档费率。价格确认不代表切换收款渠道；后续已完成爱发电本地接入与模拟测试，见 [接入记录](afdian-integration.md)；公开开售继续关闭，尚未完成真实付款。
- FAQ 的收入结算说明并非实时到支付宝；需在实际创作者后台确认所选售卖/独立方案的结算、退款、金额小数支持和准入规则。不得沿用支付宝直连“不退服务费”文案假设爱发电的退款费政策相同。
- 本次只核查资料，未创建爱发电账号/方案、未获取 Token 或 OAuth2 凭证，未启用 Webhook、未修改销售开关，未进行真实付款。

## 当前安排

如按真实开发状态申请官方 demo 并获批准，可在获准范围与有效期内做受控真钱联调；试用不代表长期准入。公开开售继续关闭。因为用户产品仍在开发，不应为了寻找支付入口而擅自购买服务器、迁站或签约收费服务。

长期方案尚待选择：取得适合真实业务的官方准入资料，或找到明确接受该业务且用户认可费用的服务平台。资金到账核验、验签、金额/订单/商户核对、幂等发码要求保持不变。
