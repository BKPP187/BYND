# 泰语逐字课堂：实现与核对记录

2026-10-19。本轮按用户指定的《基础泰语一》课堂顺序组织功能；具体语言事实使用下列公开教学资料交叉核对，不把模型推导当作规则或测验答案。

## 修改前现状

`study-reading.js` 使用现有离线 IPA 词库，能给出声母、元音、尾音、实际声调；依单音节词库片段对齐部分泰文。简单规则与词库声调相同时，才输出一句原因。词本、卡片、字表、描写及系统 TTS 已存在。缺少完整拼写解析、字母名称和位置音区分、分步推导、学习者判断和错题复习。

## 资料依据

- [NIU 声调表（John F. Hartmann）](https://seasite.niu.edu/thai/tones/tonechart.htm)：辅音类别、活死音节、死音节长短与实际五声调的关系。课堂编号采用用户要求的 1 中平、2 低、3 降、4 高、5 升；33/21/41/45/214 是教学近似，不覆盖所有说话人的精确曲线。
- [NIU 第 15 课](https://seasite.niu.edu/thai/maanii1/lesson15/structure.htm)：常见元音、变形、活死音节，อย่า / อยู่ / อย่าง / อยาก，以及 น้ำ 的书写与实际长度差异。
- [NIU 第 3 课](https://seasite.niu.edu/Thai/maanii1/Lesson3/story.htm)：前置元音与 นม 中隐含的短 /o/。旧词库误把 นม 展开为两个字母的名称；此词及声调表的 ก้า、ก๊า 使用明确的小型课堂参考，保留来源标识。
- [NIU 辅音入口](https://seasite.niu.edu/Thai/basic/alpha_cons_table.htm)：44 个辅音及三类的学习体系。模块独立保存名称、初音和尾音；ญ 初音 /j/、尾音 /n/；ด 初音 /d/、尾音 /t̚/。
- [DLTV 前引字母课程](https://dltv.ac.th/teachplan/episode/91031)及 [SRU 前引字母教材](https://readwritethai.sru.ac.th/wp-content/uploads/ebook/primary-2/khoatagun/chapter-8.pdf)：前引字母对后续低辅音的声调控制。模块支持单音节 ห นำ 和限定的四个 อ นำ ย 词；不改变被引辅音字母本身的固有类别。
- [DLTV 真复辅音资料](https://dltv.ac.th/utils/files/download/75223)：同一元音下的复辅音及第一个字母控制声调；只纳入明确组合并与本词 IPA 起音核对。
- [DLTV 假复辅音资料](https://dltv.ac.th/utils/files/download/166161)：จริง 中 จร 读 /tɕ/，ทราย 中 ทร 读 /s/。当前只对这两个明确词进行特殊处理，不把所有相邻字母通用化。

`analyze(term)` 的每个音节含 `verified`，只对拼写和本地 IPA、声调全部一致的分析展示推导或出题。它不是“全部词条已获母语教师核准”的标志。

顺序为逐字查询 → 起始组合与控制类别 → 元音名称/长度/位置 → 词尾和活死依据 → 调号名称 → 声调表推导 → 实际 IPA / 带调教学转写 → 词义、句法及语境。详细模式六步中将尾音与活死合为一步，词义语法位于整词的独立折叠区。基础模式也保留判断理由，另可展开本词的发音动作。

“คิดถึง”明确拆为 คิด / ถึง。前者 ค 低辅音、ิ 短 /i/、ด 收 /t̚/、无调号、死音节 → 第 4 调；后者 ถ 高辅音、ึ 短 /ɯ/、ง 收 /ŋ/、无调号、活音节 → 第 5 调。IPA 与教学罗马转写分列，ʉ 是教学转写中对应 IPA /ɯ/ 的记号，不使用中文谐音。句法例句把主语、谓语、宾语与词汇整体含义区分。

声调规则是三类别 × 两种长短 × 两种活死 × 五种标记的显式核对。高/低辅音的 ๊、๋ 不直接给出常规答案。低辅音「标二读三/标三读四」口诀明确限定为课堂把无标记排第一格的写法次序，不等同于 ไม้เอก / ไม้โท 的泰语名称编号，更不用于所有类别。

缺少正字法边界时，允许在 120 字符 / 40 音节上限内寻找唯一的完整拼写路径；每段必须独立通过起音、元音、尾音和声调核对，多个可能路径则不采用。短开音节的词库 IPA 有时未显写 /ʔ/，按短开音节的死音节规则处理，并明确说明未显写；不改写原 IPA，不凭空增加真实音频结论。

易混项键分别对应控制辅音、元音形态、实际尾音类和声调规则；保存错误数、后续答对数、具体词与音节。重复提交不重复计数。读取到损坏数据不覆盖；配额/权限失败保留判断反馈并显示未保存。模式偏好失败也有可见提示。没有改写词本条目和已有阅读进度。

正常示范发送泰语原文、th-TH、rate=0.92；慢速 rate=0.65。沿用系统/原生桥接，不把教学转写或 IPA 传给 TTS。缺失系统语音包、接口错误或播放错误明确提示；queued 只表示系统受理，不声称音色已人工验收。

## 仍未覆盖

跨音节的前引传调（如 สวัสดี 中的关系）、所有借词/梵巴来源词、ฤ/ฦ/รร、所有静音组合、上下文引起的长度和声调变化、方言或口语变体、任意句子的唯一词法边界，以及每个词的全部词性和语境。目前只有明确录入的词有专门语法说明；其他词保留词本释义并提示缺少本词语法数据。

词库覆盖不等同人工校对。模型回答收到本地核对事实，但没有对任意模型生成的长段教学作母语者逐句评审；这些回答不会成为测验答案。泰语音频回归使用桥接测试替身验证原文、语言和速率；真实浏览器枚举了 3 个音色，其中没有泰语（real-voice-report.json），未将路由测试冒充实际泰语音色/慢速效果的听辨验收。
