# 通话实时语音与悬浮窗

普通语音／视频通话接通后（Vivix 实时视频除外，它有自己的麦克风）：

- **一直在听**：识别出的整句话自动作为你的发言发送；输入框仍可打字。
- **插话**：角色说话时你一开口，当前这句立刻停下，排队中的句子丢弃，还在生成的回复也会取消。
  系统／浏览器识别在角色说话期间要先听到不是角色原话的字才算插话（防止扬声器回声）；接口转写模式靠回声消除和更高的音量门槛。
- **主动开口**：双方都安静后，默认 8 秒角色主动接话；连续没回应时间隔翻倍（8→16→32 秒），最多 3 次；你说话或打字后重新计数。
- **最小化**：通话页左上角按钮把通话收成悬浮球（头像 + 跳动的通话时长），可拖动、自动贴边，点一下回到通话。悬浮球跟随当前微信主题。
- **静音**：关闭麦克风，不再识别。

设置位置：设置 → 语音 → 通话实时语音（开关、识别方式、转写接口与模型、主动开口秒数）。

## 识别方式

| 设置 | 实际使用 |
|---|---|
| 自动 | APK：手机系统语音识别；浏览器：浏览器自带识别；都没有时用接口转写 |
| 只用系统 | 同上，但没有系统识别时不回退 |
| 只用接口 | 麦克风录音 → OpenAI 兼容 `/audio/transcriptions`（默认 `whisper-1`），每句话计费一次 |

系统识别连续出错 4 次或缺少权限时，会自动改用接口转写（若已配置）；都不可用时通话页提示“可以继续打字”。

## APK 专属

- 首次通话会请求**麦克风权限**。
- 通话期间常驻通知“与 X 语音通话中”，带通话计时和“挂断”按钮。
- 回到手机桌面或切到其他应用时，若已允许“显示在其他应用上层”（与后台陪伴同一个权限），屏幕边会出现**悬浮通话窗**（头像 + 计时），拖动后贴边，点一下回到 BYND。回到 BYND 自动隐藏，挂断后关闭。
- 后台期间页面继续运行（WebView 不暂停计时器），所以在桌面上也能继续说话和听角色回复。

## 需要真机验证

这些在打包 APK 后需要实测：系统识别在国产机上是否可用（部分机型没有识别服务，会回退到接口）、扬声器外放时插话是否误触发、后台时长时间通话是否被系统杀掉（必要时在手机设置里关闭电池优化）。
