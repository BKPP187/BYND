BYOK 是什么意思？

Bring Your Own Key，也就是使用你自己的模型 API Key。BYND 的购买费用与模型服务商收取的 API 使用费用分开；聊天、生图等联网功能需要对应的模型服务。

以后每次打开都要联网激活吗？

正式版计划在首次激活时联网，之后用本机保存的签名凭证离线验证授权。聊天等需要调用 API 的功能仍需要联网。换机、卸载或清除应用数据后，可能需要重新激活。

目前支持哪些设备？

这个下载入口为 Android 安装包准备。其他平台的正式销售和授权安排会另行公布。
